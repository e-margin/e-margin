プライバシーポリシー

Athena Scout ／ Chrome Extension
提供者: E-margin ／ 最終更新日: 2026-10-20

1. 本ポリシーについて

本プライバシーポリシーは、E-margin（以下「当方」といいます）が提供するChrome拡張機能 「Athena Scout」（以下「本拡張機能」といいます）における、 利用者情報および利用者が本拡張機能を通じて取り扱う情報の取り扱いについて定めるものです。

本拡張機能は社内利用に限定した業務用ツールです。社外への提供・再配布は固く禁じます。

2. 本拡張機能の目的

本拡張機能は、採用スカウトサービス（OfferBox・LabBase・キミスカ・OneCareer）の 学生プロフィール画面に表示されている情報を、採用担当者が自社の内部ツール 「Athena Scout」（https://athena-scout.jp）へ連携するために、 整形してクリップボードへコピーすることを目的とした業務用ツールです。

3. 取り扱う情報

本拡張機能は、以下のとおり利用者のブラウザ内で情報を取り扱います。 利用者本人を識別するための情報（氏名・メールアドレス・IPアドレス等）を独自に収集・送信することはありません。

項目保存場所送信先
取得フィールドのON/OFF設定 ブラウザのストレージ（chrome.storage.sync） 送信なし（Googleアカウントを通じたブラウザ間同期のみ）
学生プロフィールの表示内容 クリップボード（コピー操作時のみ）／Athena Scoutサーバー（連携操作時のみ） 利用者が明示的に操作した場合に限り、利用者自身のAthena Scoutアカウントへ送信
Athena Scoutの認証状態 Athena Scoutサイト（https://athena-scout.jp）のクッキー 送信なし（既存のログインセッションを参照するのみ）

4. 外部通信

本拡張機能が行う外部通信は、以下に限られます。

  • Athena Scout（https://athena-scout.jp）への通信
    • 利用者のログイン状態を確認するため（/api/me）
    • 利用者が「Athenaで生成」ボタンを押下した際に、取得したプロフィール内容を利用者自身のAthena Scoutアカウントへ送信するため

分析ツール（Google Analytics等）の使用、広告配信、第三者サービスへのデータ送信は一切行いません。

5. アクセス権限

本拡張機能は、以下の権限を Chrome から取得しますが、 いずれも本拡張機能の中核機能のためにのみ使用します。

権限利用目的
activeTab 利用者が明示的に拡張機能を起動した際に、現在開いているタブのプロフィール情報を参照するため
scripting 対象ページにプロフィール取得スクリプトを実行するため
clipboardWrite 取得したプロフィール情報をクリップボードに書き込むため
storage 取得フィールドのON/OFF設定を保存するため
tabs Athena Scoutタブへの切り替え・アクティブ化のため
ホスト権限 下記「対象ウェブサイト」に記載の各サイト上でのみプロフィール取得・ボタンUI挿入を行うため

6. 対象ウェブサイト

本拡張機能は、以下のサイトでのみ動作し、それ以外のサイトでは一切起動しません。

  • https://app.offerbox.jp/*（OfferBox）
  • https://*.labbase.jp/*（LabBase）
  • https://*.kimisuka.com/* / https://*.talent-p.net/*（キミスカ）
  • https://plan.onecareercloud.jp/*（OneCareer）
  • https://athena-scout.jp/*（連携先）

7. 第三者提供

本拡張機能は、利用者および利用者が取り扱う学生プロフィール情報を、 利用者自身のAthena Scoutアカウント以外の第三者に提供することは一切ありません。

8. 利用範囲および再配布の制限

本拡張機能は社内利用に限定した業務用ツールです。 社外への提供・再配布は固く禁じます。

9. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更する場合があります。 変更後の内容は、本ページまたは拡張機能の公開ページにて告知します。

10. お問い合わせ

本拡張機能および本プライバシーポリシーに関するお問い合わせは、 Chrome Web Store の開発者連絡先までお願いいたします。

English Summary

Extension: Athena Scout
Publisher: E-margin

This extension is an internal business tool that helps recruiters copy student profile information from Japanese recruiting platforms (OfferBox, LabBase, Kimisuka, OneCareer) into their own Athena Scout account.

  • No personal identifiers (name, email, IP address) are collected independently.
  • The only outbound communication is to the user's own Athena Scout account at https://athena-scout.jp (for authentication check and user-initiated generation requests).
  • No analytics, no advertising, no third-party data sharing.
  • User settings (field ON/OFF toggles) are stored in chrome.storage.sync and synced across the user's own browsers via their Google account.
  • Clipboard writes contain the student profile text extracted from the active tab, written only when the user clicks a copy button.

Permissions (activeTab, scripting, clipboardWrite, storage, tabs, and host access to the sites listed above) are used solely to deliver the extension's core functionality.

This extension is distributed for internal use only. Redistribution outside the organization is prohibited.
