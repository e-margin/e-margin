プライバシーポリシー

Pleasanter 選択レコードコピー ／ Chrome Extension
提供者: E-margin ／ 最終更新日: 2026-10-19

1. 本ポリシーについて

本プライバシーポリシーは、E-margin（以下「当方」といいます）が提供するChrome拡張機能 「Pleasanter 選択レコードコピー」（以下「本拡張機能」といいます）における、 利用者情報の取り扱いについて定めるものです。

2. 収集する情報

本拡張機能は、利用者の個人情報、閲覧履歴、入力内容、その他いかなる情報も収集・送信いたしません。

本拡張機能が扱う情報は、以下のとおり利用者のブラウザ内に閉じて完結します。

項目保存場所送信先
選択形式（Markdown / TSV）の設定 ブラウザのローカルストレージ（chrome.storage.local） 送信なし
コピー対象のテーブルデータ クリップボード（コピー操作時のみ） 送信なし

3. 外部通信

本拡張機能は、外部サーバーへの通信を一切行いません。

  • 分析ツール（Google Analytics等）を使用しません。
  • 広告配信を行いません。
  • 外部APIへのリクエストを行いません。

4. アクセス権限

本拡張機能は、以下の権限を Chrome から取得しますが、 いずれも本拡張機能の中核機能のためにのみ使用します。

権限利用目的
clipboardWrite コピー結果をクリップボードに書き込むため
storage 選択形式（Markdown/TSV）の設定を保存するため
ホスト権限 (https://manage.rikutera.jp/*) 対象サイトのグリッド要素を読み取り、ボタンUIを挿入するため

5. 対象ウェブサイト

本拡張機能は、https://manage.rikutera.jp/ 配下のページでのみ動作し、 それ以外のサイトでは起動しません。

6. 第三者提供

本拡張機能は、利用者に関するいかなる情報も第三者に提供しません。

7. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更する場合があります。 変更後の内容は、本ページまたは拡張機能の公開ページにて告知します。

8. お問い合わせ

本拡張機能および本プライバシーポリシーに関するお問い合わせは、 Chrome Web Store の開発者連絡先にお願いいたします。

English Summary

Extension: Pleasanter 選択レコードコピー (Pleasanter Selected Record Copy)
Publisher: E-margin

This extension does not collect, transmit, or share any user data. All processing occurs locally in the user's browser.

  • No analytics, no advertising, no external API calls.
  • The only data stored is the user's chosen copy format (Markdown or TSV), kept in chrome.storage.local.
  • Copied table data is written only to the local clipboard.
  • The extension runs only on https://manage.rikutera.jp/*.

Permissions (clipboardWrite, storage, and host access to manage.rikutera.jp) are used solely to deliver the extension's core functionality.
